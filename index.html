Freedial — Speed Dial New Tab

A speed dial new tab page for Chrome with groups, themes, widgets, Focus Mode and a command bar. Every feature is free, there is no account, and your dials are ordinary Chrome bookmarks that sync with Chrome.

Moving from Speed Dial 2 or FVD Speed Dial? Export there and import the file in Freedial › Preferences › System.
